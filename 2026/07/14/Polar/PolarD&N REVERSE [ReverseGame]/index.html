得到附件apk，die看一下没有看到so层，先运行看看

运行后要求输入phone和密码，随便输入后提示错误Invalid phone number or verification code

直接丢进jadx看源码，搜索错误的字符串，就可以定位到关键函数，有1000多行相当长，在上面能看到关键内容

这是解密函数，但是没有key也没有密文，往下面找找

可以在下面看到验证登录的逻辑，和登录后的游戏内容，但是完全不用去玩游戏，解密所需的内容在里面直接硬编码了，直接得到

key:

a_sd.9/1m2)d]_+=

密文:

ii5pccS1mAt2A0kpVV64zA==:C8Vw3Xoy7DYBbhHawxOVqIeqmZvSRchgcrvZygwEgDIS99DDCeXYFqysLSLJ4g3Q

根据解密函数的逻辑，通过:进行分割密文字符串，也就得到

iv : ii5pccS1mAt2A0kpVV64zA==

encryptedData : C8Vw3Xoy7DYBbhHawxOVqIeqmZvSRchgcrvZygwEgDIS99DDCeXYFqysLSLJ4g3Q

keyBytes : a_sd.9/1m2)d]_+=

接下来按照它给的逻辑进行解密就好了

这里是把用:分割的part前一部分，使用base64进行解码，也就是ii5pccS1mAt2A0kpVV64zA==

这里同理，base64解码后一部分，也就是C8Vw3Xoy7DYBbhHawxOVqIeqmZvSRchgcrvZygwEgDIS99DDCeXYFqysLSLJ4g3Q

key换byte填充，写的是AES CBC，用AES CBC模式

因此，解密脚本

没有写unpad，只是结果多出来一点乱码而已，没毛病
