JWT基本知识

Json Web Token，Json格式的网络令牌，可以理解为是一张自带加密签名的电子通信证

JWT格式

Header

告诉别人这个是JWT，以及用的什么算法

分别表示哈希256和JWT

Payload

存放用户的数据

Signature签名

主要用来防篡改，保证JWT是自己生成的

用密钥加密前两段得到签名，进行拼接

算出签名后，把三个部分拼一起，然后用.分割

Base64URL

在以上，Header和Payload都要用Base64URL进行转换

JWT 作为一个令牌，有些场合可能会放到 URL（比如 api.example.com/?token=xxx）。Base64 有三个字符+、/和=，在 URL 里面有特殊含义，所以要被替换掉：=被省略、+替换成-，/替换成_

Signature未检验签名有效性

如果没有检验签名有效性，那么可以直接修改JWT来绕过
