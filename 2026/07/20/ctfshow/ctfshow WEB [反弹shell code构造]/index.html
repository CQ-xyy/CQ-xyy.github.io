作者: CQXYY

更新于2026-07-20
WP
WEBctfshow

要求输入shellcode，若执行成功会返回execute success!，没有其它回显

了解一下反弹shell构造，反弹shell让被攻击的服务器主动连接攻击者的电脑，从而让攻击者获得服务器的命令控制权

这里可以不用反连，学习之后发现，当web可写的情况下，可以直接用>将命令写道自定义文件里，然后访问文件即可

cat flag*>>1.txt
在不确定文件名的情况下，使用flag *可以处理以flag开头的多个文件

用御剑能扫到flag.php，所以可以直接cp flag.php 1.txt也可以

得到CTF{reverse_shell_use_nc}
