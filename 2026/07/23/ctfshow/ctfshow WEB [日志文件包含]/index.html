  • LFI：本地文件包含漏洞，让服务器包含并执行本地文件
  • RFI：远程文件包含漏洞，让服务器包含并执行远程服务器上的文件

查询后知道，WEB端通常是没有访问服务器文件的权限的，但是可以尝试访问WEB端允许访问的Linux日志

  • Apache日志：Apache HTTP Server的日志，记录所有HTTP请求
  • Nginx日志：Nginx Web服务器自己的日志，记录HTTP请求和错误
  • SSH日志：系统认证日志，记录所有认证事件，通常只root可读
